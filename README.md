## 开始协作
1. Agent 阅读 [AGENTS.md](AGENTS.md)，首先从 [PROJECT_STATE.md](PROJECT_STATE.md) 恢复业务上下文。
2. 阅读 [DEC-0001](decisions/DEC-0001-framework-and-stage.md) 与 [SOP](docs/SOP.md)。
3. 领取有 owner、授权范围和验收标准的任务，交付后提交 review，Human 验收后才 done。

方法来自 [Competition OS](https://github.com/slowhot112/competition-os)，固定快照见 [OS_VERSION](docs/OS_VERSION.md)。[templates/](templates/) 与 [.github/](.github/) 可直接使用；修改方法时先服务本次比赛，再复盘回流上游。

## 目录职责
| 目录 | 内容 |
|---|---|
| competition/ | 正式规则、报名材料清单、时间与资格核查 |
| research/ | 真实工作流访谈与来源证据 |
| ideas/ | 假设，尚不构成产品承诺 |
| decisions/ | 编号决策及 Human 确认记录 |
| product/ | 方向确认后的需求、用户流程和验收 |
| technical/ | 确认后的技术方案及试验记录 |
| tasks/ | 唯一规范任务单、证据和交接 |
| daily/ | 有活动当天的进展与阻塞 |
| demo/ | 后续演示脚本、材料和反馈 |
| src/ | 方向确认并授权后的实现 |
| tests/ | 与后续实现对应的测试及说明 |

目前无产品实现，无预选赛道。优先核实赛事、报名要求和真实场景，控制前期投入；未经 Human 决策不启动产品开发或报名提交。
